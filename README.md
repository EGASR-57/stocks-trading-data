# Stock Trading Data

Download historical data from Interactive Brokers' API by first assembling a ticker universe using non-IB methods. Prompted by me being annoyed at there not being a free, sizeable stocks dataset anywhere for playing around with. Non-commercial purposes, naturally.

IB does not provide any list of tickers itself, so it must be assembled separately.

An active IB account is required, as well as an active session in either IB's Trader Workstation or IB Gateway.

> To run the API, **TWS or IB Gateway must be running.** The API has no standalone server — it talks to a live desktop instance.

#### AS IS
The universe of tickers is currently reduced to US securities, obtainable scraping nasdaqtrader (Nasdaq-traded, plus other).

## IMPORTANT · On IB
Live data downloads require paying subscriptions, and subscription are volume- and market-dependent. However, Historical data does not -- it's free . Opening an account, and downloading the trader workstation are also free-of-charge. (2026-08-20)

## Scripts

Numeric prefixes are pipeline order. They are not yet wired together; each is run by hand. `0_` indicates example code generated by Claude, which I have subsequently edited.

| Script | Does | Writes |
| ------ | ---- | ------ |
| `0_fetch.py` | Fetches one ticker's bars from TWS. Config lives in module-level constants — edit them in place. | `csv/0_<SYMBOL>.csv` |
| `1_ticker_extraction.py` | Downloads `nasdaqlisted.txt` + `otherlisted.txt`, joins on common columns, drops test issues, keeps the ETF flag. | `csv/1_ticker_extraction_nasdaq.csv` |

## Setup

`ibapi` obtained thru *interactivebrokers.ie*, but package is in PyPI 

### TWS configuration

**File → Global Configuration → API → Settings**

- Enable *ActiveX and Socket Clients*
- Enable *Allow connections from localhost only* — restricts the API to 127.0.0.1 and makes
  the *Trusted IPs* list redundant locally (TWS still binds the port on all interfaces; the
  filtering happens above the socket)
- Consider *Read-Only API* — blocks order placement outright, historical data still works
- Note the socket port
